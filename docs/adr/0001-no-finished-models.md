# ADR 0001 — reconstruct from official instructions
Status: accepted by product brief.

Use the official selected booklet as assembly evidence. Do not import complete community/third-party
models or assembly sequences. Individual part geometry remains allowed. This preserves the intended
PDF-to-3D problem and prevents an apparently successful demo from actually being a prebuilt-model viewer.
The consequence is additional part identification, pose solving and review work; that work must be visible.
