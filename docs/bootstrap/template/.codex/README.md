# Codex configuration
The project manifest is `../project.toml`; Codex configuration is `config.toml` here.
Standalone agent TOML files use name, description and developer_instructions. No model is pinned.
Use the installed client's official documentation to confirm compatibility before starting workers.
The repository does not grant itself trust or silently disable network approval.
A docs-only bootstrap may need a new Codex session for automatic discovery; explicit reads still work.
