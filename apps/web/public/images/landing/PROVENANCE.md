# Brick Playground decorative assets

Selected concept: first displayed landing option, 3 October 2026. Reference retained in
`var/evidence/landing-playground/selected-reference.png`.

These images were generated with the built-in image_gen tool from the selected design and the current
tutorial screenshot. They are decorative marketing illustrations, not official instructions, part identity
or assembly evidence. Do not use them to reconstruct or validate the model. Visible UI identifies the
artwork as illustrative. No generated imagery is used inside the tutorial renderer or source viewer.

- hero-plane.webp: red/white plane on yellow studded plinth with four loose coloured bricks; original1322×1190.
- step-brick.webp: isolated red2×4 brick, original1547×1016.
- step-booklet.webp: blue booklet with decorative plane illustration, original1547×1016; refined to remove an unwanted propeller.
- step-tutorial.webp: black tablet with illustrative plane/tutorial display, original1547×1016.

Prompt art direction: premium isometric plastic product render, selected red/white plane silhouette,
soft shadows, transparent background, no corporate logos or extra UI text. Each asset generated separately.
Original PNGs are retained under `var/evidence/landing-playground/asset-originals/`; generated source files
also remain in Codex generated_images. Converted using local cwebp at quality86 / alpha100; no resizing,
geometry edits or background replacement. Total delivered image payload is approximately544KiB.
